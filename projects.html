Project 01 / Client Work

Golden Years Tech Help

Live site ↗ Technical case study ↗

Project Goal

Build an accessible customer experience and internal operations system for a senior-focused technology support business, connecting public service requests with scheduling, technician assignment, customer history, communication, billing, and payments.

What I Built

I designed and built the public website and role-aware CRM, including the PostgreSQL data model, authentication and Row Level Security, Realtime updates, Edge Functions, audit history, and integrations with Google Calendar, Resend, and Stripe.

Tools + Systems

  • JavaScript
  • PostgreSQL + Supabase
  • TypeScript + Deno
  • Authentication + RLS
  • Google Calendar API
  • Stripe + Resend
  • Netlify + GitHub Actions
  • Accessibility

Engineering Focus

The project required system and workflow design, role-based access, transactional data integrity, reliable external integrations, background retries, payment reconciliation, deployment hardening, automated verification, and accessibility for an older customer base.

Project 03 / Community Application

Syntax Studio Resource Library

Live site ↗ GitHub ↗

Project Goal

Create a beginner-friendly coding hub that helps self-taught developers find useful tools, guides, communities, and project ideas in one organized place.

What I Built

A searchable, filterable developer resource library built around structured JavaScript data, multi-criteria filtering, project discovery, moderated community submissions, responsive layouts, and accessible interactions.

Tools Used

  • JavaScript
  • Structured Data
  • Search + Filtering
  • Formspree
  • Responsive Design
  • Accessibility

Engineering Focus

The project required turning a growing collection of resources into a usable information system: defining searchable data, combining filter criteria, handling empty and incremental result states, and keeping community submissions moderated rather than feeding untrusted input directly into the public dataset.
