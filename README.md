# Kay — Software Developer Portfolio

Personal portfolio showcasing production web applications, collaborative engineering, open-source projects, and selected creative work.

**Live site:** https://kaymade.github.io/

## About This Site

This portfolio was designed and built from scratch as a lightweight multi-page website.

It serves as both a project archive and a deeper look at the engineering decisions, collaboration, visual systems, and real-world problems behind my work.

The portfolio includes production client work, collaborative software projects, community tools, and open-source projects.

## Built With

- HTML5
- CSS3
- Formspree
- GitHub Pages

No framework or build step is required.

## Features

- Responsive multi-page layout
- Semantic HTML and navigation landmarks
- Skip-to-content navigation
- Keyboard-friendly links and controls
- Reduced-motion support
- Dedicated project case studies
- Collaborative-work documentation
- Responsive image and content layouts
- Contact form integration through Formspree

## Local Development

No dependency installation is required.

Clone the repository:

```bash
git clone git@github.com:kaymade/kaymade.github.io.git
cd kaymade.github.io
```

You can open `index.html` directly in a browser or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

The site is deployed through GitHub Pages from the `main` branch.
